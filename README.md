# gpspco — افزونه باشگاه مجریان

افزونه‌ی وردپرس «باشگاه مجریان» (Mojrian Club) — سامانه‌ی عضویت، وفاداری و ارتباط با مجریان تاسیسات مکانیکی.

- 📦 **افزونه:** [`mojrian-club/`](./mojrian-club) — نصب‌شدنی روی WordPress 6.x / PHP 7.4+ (فارسی، RTL)
- 📄 **پرامپت ساخت:** [`AGENT_BUILD_PROMPT.md`](./AGENT_BUILD_PROMPT.md) — مشخصات کامل محصول/فنی که این افزونه از روی آن ساخته شده
- 📚 راهنمای نصب و فهرست شورت‌کدها: [`mojrian-club/README.md`](./mojrian-club/README.md)

## نصب سریع

1. از **افزونه‌ها > افزودن > بارگذاری افزونه**، فایل `mojrian-club.zip` را نصب و فعال کنید.
2. هنگام فعال‌سازی، جداول دیتابیس، نقش‌ها و ۲۰ صفحه (با شورت‌کدها) به‌صورت خودکار ساخته می‌شوند.
3. از منوی **باشگاه مجریان** در پیشخوان، تنظیمات را پیکربندی کنید.

## قابلیت‌های کلیدی

- ثبت‌نام با OTP و گردش‌کار تأیید مدیر · ورود با رمز/کد یک‌بارمصرف
- موتور امتیاز (گیتا) با دفتر کل و قوانین قابل تنظیم
- ثبت پروژه، پایه فنی + استعلام عمومی، فروشگاه امتیاز، کیف پول، کارت عضویت
- دوره‌ها، بانک دانش، نظرسنجی، کمپین/قرعه‌کشی، معرفی دوستان، اعلان‌ها، تیکت
- **راهنمای باشگاه** (جست‌وجو، مقالات، FAQ) + پنل مدیریت کامل با گزارش و Audit Log
