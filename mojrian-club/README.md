# باشگاه مجریان | Mojrian Club

افزونه‌ی جامع وردپرس برای «باشگاه مجریان» — سامانه‌ی عضویت، وفاداری و ارتباط با مجریان تاسیسات مکانیکی.

## امکانات

### بخش اعضا (فرانت‌اند، فارسی و RTL)
- ثبت‌نام با تأیید موبایل (OTP) و گردش‌کار تأیید مدیر
- ورود با رمز / کد یک‌بارمصرف + بازیابی رمز با OTP
- داشبورد اعضا، پروفایل، کارت عضویت دیجیتال (با QR)
- ثبت پروژه‌ی اجرایی (با تصویر) و دریافت امتیاز پس از تأیید
- موتور امتیاز (گیتا) با دفتر کل کامل و قوانین قابل تنظیم
- فروشگاه امتیاز (تبدیل امتیاز به جوایز) با گردش تأیید/ارسال
- درخواست پایه فنی + صفحه‌ی عمومی «استعلام فنی مجریان»
- دوره‌های آموزشی، بانک دانش، نظرسنجی‌ها، کمپین‌ها و قرعه‌کشی
- معرفی دوستان (کد/لینک معرف + پاداش)
- کیف پول (اعتبار ریالی) با درخواست برداشت
- اعلان‌های درون‌سایت + پیامک (Adapter قابل تعویض)
- **راهنمای باشگاه**: هاب جست‌وجو، دسته‌بندی، مقالات آموزشی، FAQ آکاردئونی
- ارتباط با ما / تیکت

### بخش مدیریت (پنل وردپرس)
- داشبورد KPI (اعضا، پروژه‌ها، امتیازها، تیکت‌ها و...)
- مدیریت اعضا (تأیید/رد/تعلیق، اصلاح امتیاز، خروجی CSV)
- صف بررسی پروژه‌ها (تأیید/رد با دلیل + امتیاز خودکار)
- تنظیم قوانین امتیازدهی + دفتر کل + اصلاح دستی
- مدیریت پایه فنی (سطوح، نمرات، اعطای گواهی)
- درخواست‌های جایزه، کیف پول، تیکت‌ها، اعلان همگانی
- گزارش‌ها + خروجی CSV + Audit Log
- تنظیمات (برند، رنگ، درگاه پیامک، OTP، صفحات) + گزارش پیامک‌ها

## نصب

1. فایل `mojrian-club.zip` را از **افزونه‌ها > افزودن > بارگذاری افزونه** نصب و فعال کنید.
2. هنگام فعال‌سازی، جداول دیتابیس، نقش‌ها و **۲۰ صفحه** (با شورت‌کدها) به‌صورت خودکار ساخته می‌شوند.
3. از منوی **باشگاه مجریان** در پیشخوان، تنظیمات را بررسی کنید.

## نقش‌ها

- `mjc_member` — مجری عضو باشگاه
- `mjc_moderator` — ناظر (بررسی پروژه/محتوا)
- `mjc_manager` — مدیر باشگاه (دسترسی کامل به منوی باشگاه)

## پیامک (OTP و اعلان)

به‌صورت پیش‌فرض در **حالت توسعه**، پیامک‌ها در «تنظیمات > گزارش پیامک» ثبت می‌شوند تا جریان‌ها بدون درگاه قابل تست باشند. برای اتصال درگاه واقعی:

- از تنظیمات، درگاه **کاوه‌نگار** را انتخاب و کلید API را وارد کنید؛ یا
- با فیلتر `mjc_sms_send` هر درگاه دلخواه را متصل کنید:

```php
add_filter( 'mjc_sms_send', function ( $handled, $mobile, $message, $gateway ) {
	// ارسال با درگاه دلخواه؛ true/false برگردانید.
	return my_sms_gateway( $mobile, $message );
}, 10, 4 );
```

## تاریخ شمسی

تبدیل تاریخ‌ها با الگوریتم استاندارد jdf در `includes/class-mjc-jalali.php` انجام می‌شود؛ ورودی‌های تاریخ فرم‌ها شمسی و ذخیره‌سازی میلادی است.

## حذف کامل داده‌ها

برای حذف کامل جداول و داده‌ها هنگام uninstall، گزینه‌ی `delete_data_on_uninstall` را در `wp_options` مقدار `1` بگذارید (برای جلوگیری از حذف تصادفی، پیش‌فرض غیرفعال است).

## ساختار کد

```
mojrian-club/
├── mojrian-club.php        # بوت‌استرپ
├── uninstall.php
├── includes/               # هسته و ماژول‌ها (اعضا، امتیاز، پروژه، پایه فنی، ...)
├── admin/                  # پنل مدیریت، WP_List_Table، متا باکس‌ها
├── public/                 # قالب‌های عمومی
├── assets/                 # CSS/JS (RTL، فارسی)
└── languages/              # فایل‌های ترجمه
```

## حداقل نیازمندی‌ها

- WordPress 6.0+ / PHP 7.4+ / MySQL 5.7+ یا MariaDB

## توسعه

- همه‌ی خروجی‌ها Escape و ورودی‌ها Sanitize شده‌اند؛ فرم‌ها با Nonce محافظت می‌شوند.
- رویدادهای حساس در `mjc_audit_log` ثبت می‌شوند.
- قالب تک‌مطلب راهنما از `public/templates/single-guide.php` قابل override است.
